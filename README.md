# Kwentuhan: concept demo

Interactive prototype for a BU111 live case. It walks through the recommendation: a weekly family question, unlocked by a glass Coke 2-pack, answered by Lola and kept in a family tapestry.

Static site (HTML, CSS, vanilla JS), no build step. Deploy as-is on Vercel (Framework preset: Other).

- Recording uses your microphone only if you allow it, and stays in the browser.
- Receipt scan, transcription and store list are simulated with sample data.
- Type: Archivo (SIL Open Font License, see `assets/fonts/ARCHIVO-OFL.txt`).

Concept prototype for a university case competition. Not affiliated with, or endorsed by, The Coca-Cola Company.
